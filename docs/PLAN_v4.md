# Kaggriculture v4：cha22 生产执行 × 市场大脑 × TTT 快权重对手模型 × 先离线 RL × 快慢分离

## 0. 一句话
- **cha22 只负责"生产"**：农民和雇工的动作，以及所有买单（种子、动物、雇工、土地、小麦和肥料）。
- **"卖出与仓储"整条通道由我们负责**，由三部分组成：
  1. 对手预测器：DSV4 式 MoE（共享专家 + 从 replay 学出的对手风格专家），再加 TTT 快权重在对局中实时学习；
  2. 学出来的卖出策略（神经网络，分层输出）。精确价格函数、argmin 计算等规则只作为工具和老师，不再当专家；
  3. 训练顺序：先离线 RL，再在线 RL。
- **规划器删除**。两边职责不重叠，所以系统不会退化成 cha22。

## 1. 证据：为什么这样设计

### 1.1 已有实验（全部以 cha22 为基准）
| 实验 | 结果 | 含义 |
|---|---|---|
| 每天整体切换 agent 的上帝视角上限（vs cha22 镜像） | +440（同源专家）/ +514（异源专家） | 在 cha22 之上换一整套打法，空间很小 |
| cha22 的 front_run 喂入对手真实的下一步计划 | ≈0（12 局中 11 局在 ±54 以内） | 不是信息没用，而是 cha22 的钩子只看 1 步、只管 4 种商品、卖量受自己计划卖量的限制，用不上这个信息 |
| 顶尖队伍的动作带交给 cha22 底盘执行（按商店匹配世界） | 从第 6 天起用：−30,579；开局就用：−37,416 | 生产侧换成外来计划，会破坏 cha22"动作带 ↔ 修复层"的耦合 |
| 强制使用顶尖队伍的宏观专家（开局、买地、作物、卖出时间表） | −10k ~ −135k | 原因同上 |
| 带仓容保护的肥料持有专家 | 胜 34/40（基线 30/40），资金差持平 | 市场侧的改动安全，而且可能有正收益 |
| 独立规划器 | 收入约为 cha22 的 38% | 与 cha22 职责重叠且更弱，所以删除 |

### 1.2 今天核对的规则（官方解释器 `kaggriculture.py`）
1. **两个玩家之间唯一的交互渠道是共享的市场库存**。HIRE 和 BUY_LAND 只作用于各自的农场；城镇商店的解锁是随机的外生过程。
2. **库存变化**：
   - 每卖出一件，该商品的库存 +1；成交价为 1 时库存不变。
   - 城镇消耗是无条件扣减的：每 4 步，每个已解锁的商店扣 1 件（单品商店扣 2 件）；每 24 步，城镇中心扣 1 件（不含肥料）。
3. **高价品的价格曲线极陡**。相对初始库存多出下面的件数，价格就跌到地板价 1：牛奶 76 件、草莓 63 件、羊毛 59 件、甜瓜 158 件。
   - 肥料没有任何消耗，价格每多一件降 0.2，只降不回。
   - 甜瓜只有城镇中心消耗，每天 1 件。

| 商品 | 每人卖出件数 | 占收入 | 成交均价 / 基准价 | 最后 5 天卖出占比 |
|---|---|---|---|---|
| MILK | 117 | 13.9% | **46%** | 36% |
| WOOL | 69 | 6.9% | **31%** | 27% |
| MELON | 12 | 2.3% | **47.5%** | 0% |
| FERTILIZER | 271 | 17.2% | **39%** | 23% |
| STRAWBERRY | 117 | 22.4% | 99% | 42% |

- 牛奶、羊毛、甜瓜、肥料四种高价品占了 40% 的收入，成交价却只有基准价的 31–47%。
- 到第 27 天，肥料的市场库存比初始多了 440 件，价格从 100 跌到 12。

### 1.4 关键推导：市场可分解性
**定义**：对手的净流量 o 和城镇消耗 d 合起来，构成"外生库存路径"

  E_τ = I_0 + Σ_{σ<τ} (o_σ − d_σ)

**结论**：城镇消耗是无条件的，而我们每卖一件都会让库存永久 +1。所以某种商品我们累计卖出的第 m 件，如果在时刻 τ 卖出，价格恰好是 p(E_τ + m)。这里忽略两点：地板价，以及同一步内双方逐件交错成交；我方的买单记为负的卖出。由此得到四点：
1. **总收入** = Σ_m p(E_{τ(m)} + m)，只取决于两件事：一共卖多少件，以及每件卖在外生路径的哪个位置。
2. **自己分批慢慢卖本身没有价值**。这解释了为什么之前按需求分批卖出的专家没有效果，也解释了为什么只看 1 步的 front_run 没用。
3. **对手不随价格反应时，最优策略是**：每件货在它的可卖窗口 [产出时刻, 终局] 里，挑 E 最低的时刻卖出。约束有两条：
   - 仓容 100 件，日终溢出的部分丢弃，用拉格朗日乘子处理；
   - 终局还没卖掉的货价值为 0。
4. **城镇消耗是已知的，所以唯一的未知量就是对手未来的市场流量 o。这正是 TTT 应该在测试时学的东西。** 对手会随价格反应的那部分（博弈），交给 RL。

## 2. 架构
```
对手预测器 = DSV4 MoE + TTT（智能之一）
  共享专家：通用对手模型
  路由专家 ×K（≈8）：从 replay 学出，各自专精一类对手风格（囤货倾销 / 持续小批量卖 / 大量买肥料 ...）
  门控（DSV4 HGate：sqrtsoftplus 打分，负载均衡偏置只管选择）：按局内已观测的对手行为，每步重判对手类型
  TTT 快权重：在选中专家之上，每步用刚揭晓的对手流量做自监督梯度更新（应对没见过的新对手）
        │ 预测分布：对手未来 1/4/24/72 步及到终局的流量、隐藏库存、倾销时刻
        ▼
卖出策略 = 神经网络（智能之二），分层输出：商品 → 数量
  输入：状态 + 预测分布 + 工具特征（精确价格、城镇消耗表、每件货的持有收益、"此刻是未来最低点"的概率）
        + cha22 想卖多少（仅作参考特征）
  critic V/Q（IQL）：离线 RL 与在线 GRPO 的价值基线
        │ SELL 订单
        ▼
cha22（共享生产专家，固定）：农民/雇工动作 + 所有买单 ───────────────────────────► 合并成最终动作
```

| 模块 | 负责什么 | 怎么更新 |
|---|---|---|
| cha22 | 生产：所有单位动作和所有买单 | 固定，不改它的动作带和修复层 |
| 市场大脑 | 所有 SELL（以后加上"肥料自己用还是卖掉"） | 模型求解，加上慢策略给的参数 |
| TTT 预测器 | 对手未来的流量、隐藏库存、倾销时刻 | 快权重每步更新；慢权重离线元学习 |
| 门控 + critic | 当天用哪个卖出专家、用什么风险参数；以后还要选 cha22 的路线 | 先离线 RL，再在线 RL |

**MoE 只放在满足两个条件的地方**：①专家很强、彼此本质不同、剩下的时间里学不出来；②局面确实分成不同类型，不同类型下最优专家不同。
| 模块 | 条件 ① | 条件 ② | 结论 |
|---|---|---|---|
| 生产 | ✔ cha22 及其路线/层变体 | ✔ 商店组合、对手不同，最优路线不同 | 启发式 MoE：共享 cha22 + 路由 cha22 变体（以后在路线决策点开放） |
| 卖出决策 | ✘ 预测准确时规则很简单；规则的参数变体不含新知识 | — | 不用 MoE，用学出来的神经网络策略 |
| 对手预测 | 专家从 replay 学出 | ✔ 对手风格本质不同 | DSV4 MoE，全部是神经网络专家 |

- **规则的角色**：精确价格、消耗表、argmin 是网络的**工具**（提供特征）；完美预见的 argmin 卖出器是训练时的**老师**；cha22 的卖单只在报错或超时时**兜底**。盲版/保守版/激进版这类规则参数变体不再作为专家。
- **学出来的策略为什么能超过规则**：规则最优要求对手不反应、预测准确、仓库无限，现实中三者都不成立（对手会跟着抛售；不确定时卖多少要从结果里学；仓容 100、资金和小麦/肥料原料与 cha22 的生产耦合）。
- **保留现有架构**：DSV4.1 HGate（sqrtsoftplus 打分、偏置只负责选择、负载均衡）复用到对手预测器的 MoE；分层输出（SELL → 商品 → 数量）用于卖出策略；启发式 H-MoE（指针复制）留给生产侧的路线路由。
- **单位槽**：v4 全部交给 cha22。在单位槽上做路由的上限只有 +514，而且会破坏耦合；以后再开放。

## 3. TTT：放在哪、怎么更新、怎么训练

### 3.1 为什么不放进 cha22 的 front_run
把完美的对手信息喂给它，收益也约等于 0（见 §1.1）。可以顺手把 TTT 的预测接到 `opponent_plan` 上，零成本，但不指望它带来收益。

### 3.2 内环：测试时每步更新
- **输入 x_t**：
  - 市场库存偏差和价格；
  - 当前的城镇商店，由此得到确定的消耗日程；
  - 对手可见的农场：各类动物数量、各种作物的植株数和成熟度、已解锁的地块、资金；
  - 推断出的对手本步流量：u_t = ΔI − 我方流量 + 城镇消耗。成交价为 1 的卖出从库存上看不出来，用对手的资金变化补上；
  - 当前时刻。
- **TTT 层**：k_t = θ_K·φ(x_t)，z_t = k_t + W_t·k_t（TTT-Linear 残差形式）。
- **自监督任务**：用 z 预测对手接下来 h ∈ {1, 4, 24} 步的流量 y^h。这个标签 h 步之后就在对局中揭晓，不需要奖励，也不需要人工标注。
- **更新规则**：

  W_t = (1−λ)·W_{t−1} + λ·W_0 − η ⊙ ∇_W Σ_{已揭晓的样本 s} ‖V·z_s − y_s^h‖²

  - 用最近 4 步做小批量；η 和 λ 是可学习的。
  - W 是 64×64 的矩阵，每步计算量在微秒级。
- **主任务头读取 z_t**，预测三样东西：对手未来 72 步和到终局的流量、对手的隐藏库存、对手的倾销时刻。
  - 这些标签在局内不会揭晓，只在外环中训练。
  - 这正是 TTT 的原理：用局内能揭晓的短期自监督梯度，去改进对长期预测有用的共享表示。

### 3.3 外环：离线训练慢权重
- **数据**：本地共 73,406 局 replay，两个视角合计约 14.7 万条轨迹。用官方解释器精确重放，得到每一步的库存和双方的实际成交流量。
- **训练目标**：
  - 对每个时刻 t，用"当时的" W_t 做预测，此时标签还没揭晓。
  - 损失对所有 horizon 求和，用高斯 NLL 或分位数损失。
  - 梯度反传穿过 720 步的内环，学习 φ、θ_K、V、W_0、η、λ 以及各主任务头。
- **对照组**：去掉内环，即 W_t ≡ W_0 的纯慢模型。两者之差就是 TTT 的价值，对应验证门槛 G2。

### 3.4 MoE 与 TTT 如何配合
- **慢**：K 个路由专家（对手风格）和共享专家离线训练好，负载均衡偏置防止所有对手塌缩到同一个专家。
- **快·离散**：门控每步根据局内历史重新判断对手类型，几步之内就能切换专家。
- **快·连续**：TTT 快权重作用在专家输出的表示上，每步做梯度更新，贴合这一个具体对手，也覆盖训练数据里没有的新风格。

### 3.5 "不断更新"发生在三个时间尺度上
1. **局内（每步）**：快权重 W_t 跟着对手的真实行为持续更新，适应这个对手、这一局。
2. **局间（离线）**：用爬虫把我们在天梯上的新对局抓回来，加入外环数据，重新训练慢权重（W_0、η 和编码器），然后重新提交。
   - Kaggle 每局是独立进程，无法跨局保存状态，所以跨局学习只能走"抓 replay → 再训练 → 重新提交"这条路。
3. **版本间**：慢策略的改进由 RL 驱动（见 §4）。

## 4. 训练：先离线 RL，再在线 RL
- **O1：TTT 外环自监督**（§3.3），不需要奖励。
- **O2：特权教师（MOPD）**
  - **市场重放对手**：把 replay 里对手的动作开环重放。因为市场是唯一的交互渠道，这对我们来说几乎就是一个精确的对手模拟器。
  - 在这个模拟里构造一个完美预见的 argmin 卖出器，作为教师。它掌握学生在测试时拿不到的特权信息。
- **O3：离线 RL（IQL）**
  - **数据集**由两部分组成：
    1. replay 中所有玩家的卖出决策（卖出的动作空间对所有玩家通用）；
    2. 模拟数据。我方用 cha22 生产，卖出行为策略混合多种（cha22 原版、盲版 argmin、3 个带仓容保护的 DemandAware 规则、教师、ε 扰动），只为覆盖足够多样的行为；对手包括联赛 agent 和市场重放的顶尖队伍。
  - **奖励**：r = 胜负 + 0.25·tanh(资金差 / 15000)。
  - **方法**：用期望分位回归学 V，用 TD 学 Q，再用 AWR 抽取卖出策略（商品 → 数量）。
  - **保守改进**：偏离 cha22 的幅度由优势大小来门控。
- **O4：在线蒸馏**
  - 学生（TTT + 慢策略）自己跑对局；在学生实际访问到的状态上，用教师的标签做蒸馏，损失为反向 KL。
  - 多教师 = 完美预见教师 + critic 判定的最优专家。
- **在线 RL：关键步分叉 GRPO**
  - **关键步**：每天的卖出计划，以及大额卖出决策。
  - **分支**：用 `FarmEnv.clone` 分出 G 个分支，之后都用当前策略继续。
  - **优势**：A = R − mean(R)，按 CodeMidas 不做 std 归一化。
  - **损失**：MiMo 式 stop-grad ratio，上下截断解耦，外加对离线策略的 KL。
  - **对手**：会随价格反应的联赛 agent，以及自博弈，专门学习"抢在对手之前卖"的博弈部分。

## 5. 快慢分离
| 尺度 | 运行什么 | 预算 |
|---|---|---|
| 快（每步） | 门控重判对手类型 → TTT 更新 → 预测分布 → 卖出策略网络给出 商品 → 数量；其余动作由 cha22 给出 | < 20 ms |
| 慢（每天第 0 小时、有新商店解锁、检测到对手倾销时） | 用工具重算全程特征（每种商品的持有收益、最低点概率）；可选：用自带的 FarmEnv 对预测做一次分叉模拟 | 单次 ≤ 0.5 s；整局从 60 s 超时储备中最多用 20 s |
| 跨局（离线） | 外环元学习、IQL、GRPO、天梯 replay 回流 | GPU 约 3–5 小时 |

## 6. 为什么不会退化成 cha22
1. **结构上**：SELL 通道由学出来的卖出策略负责（初始化来自完美预见老师的蒸馏，而不是 cha22）。cha22 的卖单只作为参考特征，以及异常、超时时的兜底。
2. **指标上**：
   - 四种高价品的成交均价从基准价的 31–47% 提升到 ≥ 60%；
   - 用分叉 A/B 做每类偏离的归因，看胜率和资金差；
   - 偏离率（我方卖单与 cha22 卖单不同的步数占比）必须显著大于 0，且偏离的价值为正。
3. **以后开放**：门控在 cha22 的路线决策点（第 144 步、第 648 步）读取对手画像来选路线。先用路线上帝视角实验（G4）量出上限。
